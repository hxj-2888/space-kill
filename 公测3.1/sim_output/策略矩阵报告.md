# 太空杀 公测3.1 策略矩阵报告（三方风格交叉对战）

模拟：**18 组合 × 2000 局**高水平对战（种子 90000）。规则版本：公测3.0（R1~R11 + 感染体系v3 + 倒计时24 + 补刀第4夜）。
异形流派已收敛为 **击杀流 kill / 破坏流 sab / 感染流 infect**（原 mix 混合分工、balanced 均衡、mimic 拟态渗透已移除）；**感染是行动权重表中的显式权重项**，三大流派共用"视情形而定"的权重化觉醒与转化。
默认参数：TRUSTED_LR=5.0 / ORDINARY_LR=1.12 / 记忆衰减0.97 / 情绪+追责+质询+引述全开。**规则数值未改动**，仅切换策略权重。

## 策略含义

| 阵营 | 风格 | 行为要点 |
|---|---|---|
| 人类 | std 标准广播 | 神探第2夜起有情报跳身份；船员双查锁定 70% 指认 |
| 人类 | passive 信息沉淀 | 神探永不跳；情报走私聊 |
| 人类 | aggro 激进广播 | 有情报必跳必指认 |
| 异形 | kill 击杀流 | 行动权重出刀最高；觉醒偏击杀（偶数夜双刀）；视情形转化为收割 |
| 异形 | sab 破坏流 | 行动权重破坏最高；觉醒偏破坏推停摆；净破坏封顶/残局时转化出击杀 |
| 异形 | infect 感染流 | 行动权重感染最高（感染为显式权重项）；觉醒偏感染，感染打满目标数 |
| 外星 | std 标准渔翁 | 建图→第6夜双刀→高价值收割 |
| 外星 | hunter 猎手双刀 | 第6夜 98% 觉醒，尽早双刀 |
