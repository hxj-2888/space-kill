# 太空杀 公测3.1 策略矩阵报告（三方风格交叉对战）

模拟：**24 组合 × 2000 局**高水平对战（种子 90000）。规则版本：公测3.0（R1~R11 + 感染体系v3 + 倒计时24 + 补刀第4夜）。
默认参数：TRUSTED_LR=5.0 / ORDINARY_LR=1.12 / 记忆衰减0.97 / 情绪+追责+质询+引述全开。**规则数值未改动**，仅切换策略风格钩子。

## 策略含义

| 阵营 | 风格 | 行为要点 |
|---|---|---|
| 人类 | std 标准广播 | 神探第2夜起有情报跳身份；船员双查锁定 70% 指认 |
| 人类 | passive 信息沉淀 | 神探永不跳；情报走私聊 |
| 人类 | aggro 激进广播 | 有情报必跳必指认 |
| 异形 | mix 破坏混合分工 | 首只觉醒占破坏，其余感染→击杀（第3夜 90% 转化）；团结/混淆协同投票 |
| 异形 | aggro 极限击杀 | 全员出刀为主，感染<40%，不结茧 |
| 异形 | sab 破坏停摆 | 觉醒/转化全优先破坏，推停摆阈值 |
| 异形 | mimic 拟态渗透 | 投票指控完全混入人类票型，私聊不撒谎 |
| 外星 | std 标准渔翁 | 建图→第6夜双刀→高价值收割 |
| 外星 | hunter 猎手双刀 | 第6夜 98% 觉醒，尽早双刀 |
