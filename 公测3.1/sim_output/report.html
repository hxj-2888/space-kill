④ 收敛曲线（噪声率随夜数衰减 → 各档平台期）

噪声率 = (base + 0.25·panic)·e^(−夜/τ) + floor。三档 τ/floor 不同 → 收敛速度与上限不同；panic 注入使倒计时危机期噪声回升（情绪驱动偏差）。

⑤ 信念演化（第 0 局 · expert 人类对存活异形的平均后验）

expert 后验应随信息积累缓升且稳定 < 1.0（绝不逼近确定=绝不透视）；真实异形身份只有裁判知道（上帝最优上界=1.0，仅作对照）。

⑥ 情绪轨迹（第 0 局 · 全体存活者均值）

事件驱动：被投票→fear/anger↑；高信任对象死亡→anger↑；倒计时≤8 或人数劣势→panic↑（噪声随之↑）；查验确证异形→confidence↑。情绪非纯随机，全部由对局事件触发。

⑦ 私聊效果分析

私聊总次数 17888；有效私聊（48h 内对私聊对象产生行为变动）10423 次 → 有效率 58.3%（裁判层判定，与 3.0 口径一致）。
