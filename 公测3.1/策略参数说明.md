# 太空杀 公测3.1 主流策略关键参数说明

> 本文面向规则调平：列出每个主流策略的行为逻辑与**可调关键参数**（数值出处 = `太空杀_公测3.1_模拟代码.py` 模块常量）。
> 当前默认组合：**人类 std ｜ 异形 kill（击杀流）｜ 外星人 hunter**（矩阵实测见 `sim_output/策略矩阵报告.md`）。
> 本次改动：异形流派收敛为 **破坏 / 击杀 / 感染** 三大类，原 `mix` 混合分工、`balanced` 均衡、`mimic` 拟态渗透已移除；
> **感染被明确为行动权重表中的一项显式权重**；三大流派共用同一套"视情形而定"的权重化**觉醒 / 转化**决策。

## 一、异形三大流派的权重体系

三项决策（**觉醒方向 / 转化 / 当夜行动**）全部采用「流派基础权重 × 情境系数 → 加权抽样」，
不再使用固定顺序表或硬编码分支概率。技能档噪声通过 `ACTION_NOISE_COEF` 把权重向量向均匀分布展平
（1.0 = 完全展平；实测过强会显著拖垮异形，定版 0.35）。

### ① 当夜行动权重 `ALIEN_ACTION_WEIGHTS`

| 流派 | 出刀 | 感染 | 破坏 | 结茧 |
|------|------|------|------|------|
| `kill` 击杀流 | **1.30** | 0.35 | 0.10 | 0.03 |
| `sab` 破坏流 | 0.16 | 0.12 | **1.85** | 0.06 |
| `infect` 感染流 | 0.35 | **1.60** | 0.10 | 0.03 |

破坏封顶：`SAB_NET_CAP = 9.0`——净破坏达到停摆阈值 9.0 后，破坏权重乘 `W_SAB['cap']=0.02` 归零
（破坏直接叠加倒计时对人类不利，故封顶设在 9.0 之后而非旧版 7.0）。

### ② 行动权重的情境系数（乘法，全部来自合法观测）

| 组 | 系数 | 默认 | 触发条件与含义 |
|----|------|------|----------------|
| `W_INFECT` | `awak_dir` | 1.80 | 自身为感染觉醒方向（感染第2夜死、目标数 2~3） |
| `W_INFECT` | `off_dir` | 0.70 | 非感染方向（第3夜才死、目标数 1~2，收益打折） |
| `W_INFECT` | `early` | 1.25 | 第5夜前——感染需跨夜结算，越早种下收益越高 |
| `W_INFECT` | `fresh` | 1.30 | 未感染人类 ≥4：扩散面充足 |
| `W_INFECT` | `press` | 0.55 | 倒计时 <9：来不及等感染结算 |
| `W_INFECT` | `endgame` | 0.50 | 存活人类 ≤4：残局要即刻减员 |
| `W_INFECT` | `overload` / `overload2` | 1.25 / 1.40 | 场上已有 1 / ≥2 名感染者：医生每夜仅一记出手，压制溢出 |
| `W_KILL` | `finish` | 1.90 | 场上有濒死者可补刀 |
| `W_KILL` | `endgame` | 1.60 | 存活人类 ≤4 或 倒计时 <9 |

### ③ 觉醒方向权重 `ALIEN_AWAKEN_WEIGHTS`（替代固定顺序表）

| 流派 | 击杀 | 感染 | 破坏 |
|------|------|------|------|
| `kill` | **2.20** | 0.70 | 0.25 |
| `sab` | 0.35 | 0.60 | **2.60** |
| `infect` | 0.50 | **2.80** | 0.30 |

情境系数 `AWAK_CTX`：`occupied` 0.25（队友已占该方向，永久占位制）｜`infect_early` 1.40（第4夜前）｜
`infect_many` 1.20（人类 ≥8）｜`kill_press` 1.15（倒计时 <12）｜`kill_few` 1.12（人类 ≤6）｜
`sab_high` 0.50（净破坏 ≥5）｜`sab_late` 1.30（倒计时 ≥15 且净破坏 <3）。

### ④ 转化（觉醒方向切换）`ALIEN_TRANSFORM`

三大流派共用「目标方向情境价值 ≥ 当前方向 × `TRANSFORM_GAIN_TH`」才转化的估值门（转化当夜无行动，须值回票价）：

| 参数 | 默认 | 含义 |
|------|------|------|
| `ALIEN_TRANSFORM[style]` | (最早夜 3, 基础概率 0.85, 方向权重表) | 击杀流偏击杀 1.60；破坏流偏破坏 1.70；感染流偏感染 1.50 |
| `TRANSFORM_GAIN_TH` | 1.75 | 价值倍数门槛（低于此值不转化，避免为转化而空转） |
| `TRANSFORM_PROB_GAIN` | 0.35 | 超阈部分折算为转化概率的系数（上限 0.98） |
| `TRANSFORM_MIN_STAY` | 1 | 首次转化需觉醒后间隔 1 夜；第 2 次转化 +2 夜 |
| `TRANSFORM_VAL` | 见代码 | 方向估值：`kill_press` 1.60 / `infect_early` 1.50 / `sab_headroom` 1.40 / `sab_endgame` 0.45 / `off_dir` 0.80 等 |

### ⑤ 感染目标选择 `decide_infect`

- 排除异形 / 已感染者 / 濒死者（濒死再感染无边际收益）
- 优先公开暴露者（跳身份 / 维修暴露）+2.0，优先信息枢纽（私聊频繁）+0.35/对象（上限 1.5）
- 我曾感染过的目标 −1.5（被治好后带抗体，再感染大概率被挡）
- 目标数按规则 5.4：感染觉醒 2~3 名，其余 1~2 名；`ALIEN_INFECT_MAX['infect']=True` 时感染流打满 3 名挤爆治疗额度

## 二、人类策略（HUMAN_STYLE）

| 风格 | 行为要点 | 关键参数 |
|------|----------|----------|
| `std` 标准广播 | 神探第2夜起有情报跳身份；船员双查锁定 70% 指认 | 投票阈值 0.35 |
| `passive` 信息沉淀 | 神探永不跳；情报走私聊 | 跳身份 = 0 |
| `aggro` 激进广播 | 有情报必跳必指认（也成为异形优先出刀目标） | 跳身份 = 100% |
| `skeptic` 交叉质疑 | `TRUSTED_LR` 减半、说谎反向加倍 | 乘数 0.5 / 0.4 |
| `guardian` 护盾协防 | 船员维修倾向 +20%；保护高信任对象 | 维修加成 0.2 |

## 三、外星人策略（FOREIGNER_STYLE）

| 风格 | 行为要点 | 关键参数 |
|------|----------|----------|
| `hunter` 猎手双刀（默认） | 第 6 夜 98% 觉醒双刀；高价值目标确定性收割 | `awaken_p=0.98` |
| `std` 标准渔翁 | 前期查验建图（known<3 时 70% 查验）→ 收割 | 建图阈值 3 |
| `kingmaker` 搅局者 | 人类 ≥6 时投票 scapegoat；净破坏 ≥5 即破坏 | `sab_gate=5.0` |

## 四、未采用的规则层旋钮（按本次约定）

下列旋钮可继续把均衡推向 40/35/25，但本次**仅保留策略层改动，不施加规则数值削弱**，故均未启用：

1. 感染死亡夜 第3夜 → 第2夜（异形大增强）
2. 救援医师额度 3 → 2（削弱人类濒死挽回）
3. 补刀起始夜 第5夜 → 第4夜
4. 停摆奖励 3.0 → +1.5（破坏流价值↑）
5. 神探查验 每夜1人 → 每2夜1人（人类信息引擎减速）

> 结论：纯策略权重调参已把异形推到自身上限区间；剩余缺口（异形 ≈ +5pp、外星人 ≈ +3pp）
> 属规则层平衡范畴，需由上述旋钮补齐并重新 A/B。
