🚀 太空杀 · 星途归航 剧情 规则

太空杀：三阵营对抗规则 v1.2（正式发布版）

第一章：游戏基础配置与全局胜利条件

1.1 基础人数与阵营构成

· 总人数：15人。

· 人类（11人）：普通船员×4、工程师×1、警察×1、生化专职医师×1、救援专职医师×1、神探×1、保镖×1、验票官×1。

· 异形（3人）：所有异形初始能力相同，无特化区分。

· 外星人（1人）：独立作战。

1.2 昼夜交替

· 先夜晚行动，后白天讨论投票。白天禁止私聊（异形队内亦禁）。

1.3 胜利条件

任意阵营达成胜利条件的瞬间，游戏立即结束，终止所有结算。

阵营 胜利条件

人类 ① 倒计时胜利：初始20昼夜，每夜自然-1。任意结算时刻倒计时≤0、且未触发船体停摆·9.0阈值、且至少1名人类存活（含濒死）→ 人类胜。② 清场胜利：所有异形和外星人均被淘汰。

异形 所有非异形角色被淘汰，场上仅剩异形。

外星人 场上仅剩外星人1人。

注释①：9.0阈值触发后，倒计时胜利永久失效，但清场胜利（全歼异形与外星人）仍然有效。

若倒计时≤0但已触发9.0停摆失效，人类不能以此获胜。若人类全灭，优先检查1.4节。

1.4 人类全灭·夜晚交锋模式

· 触发条件：任意方式（夜间死亡或白天放逐）导致人类存活为0，且异形与外星人均存活。【注释②】

· 规则：

· 取消白天，仅保留夜晚行动与死亡公告。

· 倒计时、维修、破坏、停摆全部冻结（数值不再变化）。

· 异形保留全部技能（含觉醒能力）；外星人保留全部技能。

· 取消全局私聊，仅保留异形队内私聊。

· 战斗模式：双方持续行动直到一方被全部消灭，存活方赢得最终胜利。

· 单挑例外：若处于单挑模式（异形1只 vs 外星人1只），连续3个夜晚未分胜负 → 外星人胜利。此条优先于兜底终止条款。

· 兜底终止：若交锋连续5夜未发生任何减员（含感染延迟死亡），强制按人数判定：异形人数＞外星人 → 异形胜；外星人人数≥异形 → 外星人胜。

· 同归于尽：若某夜结算后异形和外星人存活数同时归零 → 外星人胜。

· 感染延迟死亡计入判定。

注释②：白天放逐导致最后一名人类出局时同样触发1.4模式。

边界注释①：1.4模式下步骤0.5感染抑制照常执行，仅步骤4a/4b被跳过；感染延迟死亡正常结算；累计破坏量锁定不变，阈值检查不再执行。

边界注释②："连续3夜/5夜未分胜负"的计数器在阵容比例发生任何变化后重新清零起算。

1.5 白天放逐揭示

· 白天投票阶段，若某玩家因累积票数最高被放逐，系统将立即公告其身份：

· 人类 → 公告具体职业。

· 异形 → 公告"异形"（不披露觉醒/转化方向）。

· 外星人 → 公告"外星人"。

· 本公告与步骤9夜间死亡公告（人类职业不公开）分别执行，互不覆盖。

· 放逐揭示后立即检查胜利条件，若触发则游戏结束；若未触发则进入对应夜晚。

注释③：放逐投票规则：得票最高者被放逐。平票（多人并列最高）则无人被放逐，直接进入夜晚。不存在"二次投票"或"随机"机制。

注释④：濒死者白天投票权不受影响（仅夜间技能失效）。

第二章：通用状态与夜晚流程

2.1 状态定义

状态 效果 生效/失效时刻

濒死 失去全部行动能力。除医生自救外，所有主动行动与被动技能全部失效；仍计入存活人数；再次受任何伤害立即死亡（跳过濒死，直接死亡）。 持续至被救援成功，成功后立即移除濒死并恢复全部技能。

全能免疫 抵挡所有杀害行为（出刀/枪击/外星人伤害）与感染施加；无法抵消已生效感染导致的延迟死亡。多层免疫时逐层消耗。 施加当夜有效，白天阶段开始时清空所有层数。

沉默 次夜无法执行任何夜间技能；次日白天投票强制弃权；白天可发言。每名玩家全局仅触发1次，后续沉默源对其无效。来源：外星人觉醒双刀。 次夜结束时失效；次日白天投票结束后失效。若在沉默生效前死亡，沉默消失且不计入全局触发。

船体停摆 永久性DEBUFF，不可逆（见3.3节）。 永久不可逆。

免疫叠加消耗优先级（伤害到达时按顺序检测，命中即消耗一层）：

1. 保护类（保镖、武装船员施加的保护）

2. 巡逻类（警察巡逻施加的免疫）

3. 被动免疫（工程师第1夜、外星人夜晚免疫）

4. 护盾类（异形结茧）

同类型按施加时间 后进先出（栈式） 消耗。

注释⑤：同夜多重同类伤害依次判定：警察开枪优先于武装船员优先于异形出刀；同职业按编号升序。免疫逐次消耗直至耗尽。若无免疫则第一发造成濒死，第二发直接死亡。

2.2 夜晚行动顺序（固定，不得调换）

步骤 内容 关键边界

0 私聊 每人1次发起权+1次接受权；濒死/沉默/感染抑制者无权；不可连续两晚向同一目标发起；异形队内不受限但仅夜间。配对需双向确认。公告配对双方编号。

0.5 感染抑制 自身有感染状态时自动获得1次抑制额度（每次感染独立获得）。可选择使用→当夜所有主动技能失效。若当夜医生清除感染，额度作废。若额度未使用且感染持续存在，下一夜重新获得1次额度（顶替原额度）。【注释⑥】 外星人使用抑制时自动放弃当夜三选一行动。

0.6 异形觉醒/转化 + 转职 第3夜起每夜触发。觉醒/转化/转职均为可选操作，三者并行结算无先后顺序。觉醒与转化不得在同一夜执行【注释⑦】。额度已满导致失败时不消耗次数。

1 外星人查验 获知一名玩家真实身份（编号+职业/阵营），无视隐藏效果。被查验者收到提示。

2 查验与巡逻 神探、普通船员同步结算；警察巡逻（仅第1/2/3夜可用）指定1~3人获全能免疫。公告巡逻人数、查验总次数。

3 保镖保护 指定1人获全能免疫，不公告。

4a 维修（毛减量计算） 强制计算：毛减量 = 1.0(自然) + 工程师基础 + 追加 + 普通船员协助 + 加速工程师。普通船员需主动选择"协助维修"方可贡献【注释⑧】。维修次数照常累计。若当夜4b外星人破坏，毛减量被追溯锁定归零。已执行维修不受本夜后续死亡影响【注释⑨】。

4b 破坏（破坏量结算） 先异形后外星人。公告破坏次数及增量、当前倒计时、破坏量。破坏量 = max(0, 异形破坏总和 + 外星人破坏总和 - 毛减量)。若外星人执行破坏则毛减量归零。异形基础+1.5，破坏觉醒+3.0；外星人+3.0。异形破坏后步骤7不再行动。【注释㉒】

5 外星人击杀/双刀 普通击杀或觉醒双刀。双刀两刀均可各自施加沉默【注释⑩】。公告攻击次数及抵挡次数。

6 警察/武装船员开枪/保护 公告警察开枪X次、武装船员Y次、共Z次、抵挡W次。

7 异形行动 每只异形从出刀/感染/结茧中选择一项（已破坏者跳过）。出刀命中濒死目标时直接死亡【注释⑪】。公告异形行动X次（抵挡Y次）。击杀觉醒者在偶数夜额外出刀【注释⑫】。

8 医生救援/治疗 执行顺序：①外星人自我治疗 ②生化专职医师 ③救援专职医师。救援成功时立即移除濒死并恢复全部技能。公告各职业次数。

9 死亡结算与胜利检查 ①结算当夜濒死伤害（再次受击者直接死亡）；②结算感染延迟死亡（感染后下下夜）；③公告死亡名单（人类职业不公开）；④立即检查胜利条件，触发则结束；否则若人类全灭且异形/外星人存活，转入1.4节。

10 验票官紧急会议 仅当步骤9未触发胜利且全场存活≥5且验票官存活（含濒死）时可用。一经发动即消耗全局次数【注释㉓】。公开身份，追加投票。投票规则复用1.5节全部规则（仅存活玩家参与、平票处理、身份公告、放逐立即生效）【注释⑭】。若未触发胜利则照常执行步骤11【注释⑬】。

11 最终倒计时结算 仅当仍有人类存活且未触发9.0失效时执行。倒计时≤0→人类胜；否则进入白天。

注释⑥：抑制额度每次感染独立获得。若额度未使用且感染持续存在，下一夜重新获得1次额度覆盖旧额度。若在使用前被治愈则作废。

注释⑦：觉醒与转化不得在同一夜执行。异形觉醒后最早在下一个夜晚才能选择转化。

注释⑧：普通船员需主动选择"协助维修"方可贡献维修值，每晚在"协助维修"与"查验"之间二选一。公式中X为步骤0.6时当前存活且尚未转职的普通船员总数（含濒死），用于计算每名选择维修者的贡献单价（边际递减效应）。例：X=4时，单价=-0.20-0.05×3=-0.35，若有2名船员选择维修，总贡献=-0.35×2=-0.70。

注释⑨：步骤4a执行的维修一经完成即永久生效，不受本夜后续死亡影响。

注释⑩：双刀两刀均可各自施加沉默。每名玩家全局仅触发1次沉默。

注释⑪：异形出刀命中濒死目标时直接死亡（跳过濒死结算）。

注释⑫："偶数夜"基准为游戏绝对夜数（第2、4、6……夜）。选择后至少后天（觉醒后第二个夜晚）才能触发；若该夜为奇数则顺延至下一偶数夜。

注释⑬：紧急会议若未触发胜利，照常执行步骤11。

注释⑭：紧急会议投票完全复用1.5节全部规则——仅存活玩家参与、平票则无人放逐、放逐后公告身份并检查胜利、放逐结果立即生效。

注释⑳：普通船员首次查验时，若当前存活人类职业种类≤1，直接揭示真实职业。

注释㉒：破坏量 = max(0, 异形破坏总和 + 外星人破坏总和 - 毛减量)。累计破坏量跨夜累加。阈值判定：分步达到时3.0→+1.5，6.0→+3.0，9.0→锁定（无增量）。跳档（<3.0直达≥9.0）：仅触发9.0锁定，3.0/6.0增量作废。

注释㉓：验票官紧急会议一经发动即消耗全局次数，无论投票结果如何（含平票）。

注释㉔：进入1.4模式后累计破坏量锁定不变，阈值检查不再执行。

2.3 私聊配对机制

1. 每名存活玩家拥有1次发起权+1次接受权。

2. 可向任意一名其他存活玩家发出邀请，可弃权。

3. 被邀请者从多个邀请中选择1个接受，或全部拒绝。

4. 配对成立条件：发起方和接收方相互选中（A邀请B且B同意A）。

5. 配对成功后发起方消耗发起权，接收方消耗接受权。

6. 配对失败不消耗发起权。

7. 私聊内容仅配对双方可见。

8. 同一玩家不得连续两晚向同一目标发起私聊。

9. 公告所有成功配对的双方编号。

异形队内私聊不受本机制限制，不占用公共权限，不产生公告。

2.4 觉醒/转化与转职的阶段划分

① 普通船员转职判定：在白天投票结束后的夜晚步骤0.6，按全场存活人数判定（全场≤5或已至第6夜）。可选，放弃后机会永久保留。转职当夜生效，公告不公开编号。【注释⑮】

② 异形觉醒判定（第3夜起）：未觉醒存活异形可选是否觉醒，放弃后可重试。放弃不占额度。觉醒后立即生效。觉醒与转化不得同夜执行。【注释⑦】公告不披露方向/编号。

③ 异形转化判定（第3夜起）：已觉醒异形可选是否转化，放弃后可重试（受次数上限约束）。转化当夜放弃行动。若转化次夜步骤0.6前死亡/濒死，转化作废（不公告、不计次数）。转化公告次夜步骤0.6结束时发布（延迟一夜）。

注释⑮：转职机会触发后永久保留。因濒死仍计入存活，不存在"人数回升"概念，无需重新判定条件。

第三章：核心数值机制

3.1 倒计时增减来源

行为 数值 边界

每夜自然流逝 -1.0 固定，但若当夜外星人破坏则锁定无效。

工程师基础维修 第1/2夜 -0.5；第3夜起 -1.5 可放弃。

工程师追加维修 -0.5（全局3次） 须在基础后立即追加；每夜最多1次【注释⑯】；计入暴露标记。

普通船员协助 -0.20 - 0.05×(X-1)，X=步骤0.6时存活未转职普通船员总数（濒死计入） 主动选择协助维修时生效【注释⑧】；选择协助的每名普通船员均按此值贡献。

加速工程师 -0.75 转职获得，独立行动。

异形破坏（未觉醒） +1.5 累计3次后下一白天公开编号+身份；若当夜后续死亡仍正常公告【注释⑰】。

异形破坏（破坏觉醒） +3.0 同上。

外星人破坏 +3.0（全局1次） 使用当夜毛减量归零。

船体停摆3.0触发 当夜倒计时 +1.5 仅当尚未触发9.0时有效【注释㉒】。

船体停摆6.0触发 当夜倒计时 +3.0 仅当尚未触发9.0时有效【注释㉒】。

船体停摆9.0触发 人类永久失去倒计时胜利 不追加倒计时增量【注释㉒】。

注释⑯：工程师追加维修全局共3次，每夜最多使用1次。

注释⑰：异形累计破坏达3次后次日公告；若当夜后续死亡，公告中标注已死亡状态。

3.2 破坏量计算

```python

# 步骤4a - 毛减量计算

gross_reduction = 1.0 + engineer_base + engineer_extra + crew_assist + accel_fix

record_repair_counts() # 仅记录次数，不参与倒计时

# 步骤4b - 破坏量结算

alien_lock = False

xeno_damage = sum(异形破坏值)

if 外星人选择破坏:

alien_damage = 3.0

alien_lock = True

else:

alien_damage = 0

if alien_lock:

gross_reduction = 0

destruction = max(0, xeno_damage + alien_damage - gross_reduction)

cumulative_destruction += destruction

# 【注释㉒】阈值检查逻辑

threshold_bonus = 0

# 情况1：累计破坏量≥9.0 → 直接锁定，不追加增量

if cumulative_destruction >= 9.0 and not triggered_9:

triggered_9 = True

human_timer_win = False

# 3.0/6.0增量作废，不追加

# 情况2：累计破坏量在9.0以下，逐档检查

elif cumulative_destruction >= 6.0 and not triggered_6:

threshold_bonus += 3.0

triggered_6 = True

if not triggered_3:

threshold_bonus += 1.5

triggered_3 = True

elif cumulative_destruction >= 3.0 and not triggered_3:

threshold_bonus += 1.5

triggered_3 = True

# 仅在未触发9.0时追加倒计时

if not triggered_9:

countdown += destruction + threshold_bonus

```

3.3 维修者暴露标记

· 工程师（含基础与追加）、普通船员、加速工程师各自独立记录累计维修次数。

· 计数达3次时，步骤4a结算后立即向所有异形和外星人公布其编号与具体职业。

· 仅触发一次，跨夜保留。追加维修计入工程师累计次数。

· 维修毛减量被锁定时，维修次数仍照常累计。

3.4 感染机制

· 适用对象：存活人类与外星人（异形自身免疫）。

· 层数上限：1层，同晚多名异形指定同一目标不叠加。

· 感染目标数：异形每夜自主选择1~2名（觉醒后2~3名），无额外消耗。【注释⑱】

· 死亡时序：感染后第二个夜晚（下下夜）步骤9触发。

· 抑制：0→1层时步骤0.5自动获得1次额度。可选择使用→当夜所有主动技能失效，死亡延后1夜。外星人使用抑制时自动放弃当夜三选一行动。额度未使用且感染持续存在时，下一夜重新获得1次额度覆盖旧额度。【注释⑥】

· 治疗：医生"感染治疗"清除1层。生化专职医师的感染治疗可对任意目标使用，但自身免疫故对自身无效。【注释⑲】

· 抗体：生化专职医师的治疗/救援赋予抗体（下一夜免疫，不跨夜）；自身免疫异形感染。

· 感染反馈：被清除/抑制时施加者收到提示（不透露患者/医生/抑制者编号）。

· 沉默与抑制叠加：沉默优先覆盖抑制；沉默结束后抑制剩余额度继续生效。

注释⑱：异形每晚在1~2名（觉醒后2~3名）范围内自行决定感染目标数。

注释⑲：生化专职医师感染治疗可对任意存活玩家使用（含自身），但自身免疫感染，治疗自身无效果。

第四章：人类阵营

4.1 普通船员（4人）

· 首次查验：目标为人类→排除一条非真实职业；目标为异形/外星人→告知"该玩家不是人类"。若存活人类职业种类≤1，直接揭示真实职业。【注释⑳】

· 累计查验：同一目标累计两次（跨夜保留）后揭示真实阵营。目标在两次间死亡或转职则进度清零。【边界③】

· 被查者提示：首次→"你被船员查验了"；第二次→"你的真实阵营已被锁定"。

· 每晚可在"协助维修"与"查验"之间二选一：选择"协助维修"按公式 -0.20 - 0.05×(X-1) 贡献维修值（X=步骤0.6时当前存活且尚未转职的普通船员总数，含濒死），选择维修的每名船员均按此值贡献【注释⑧】；选择"查验"进行个人查验（见上）。

· 转职条件：步骤0.6判定全场存活≤5或第6夜保底。可选，放弃后机会永久保留。公告不公开编号。【注释⑮】

· 转职方向（三选一，不可逆）：

· 武装船员：①1发子弹（步骤6开枪，造成濒死，被抵挡即消耗）；②1次保护机会（步骤6选"保护"代替"开枪"，施加全能免疫）。保护与开枪互斥。转职后原查验永久失效。

· 加速工程师：独立维修 -0.75（步骤4a），触发暴露标记。转职后原查验永久失效。

· 临时医生：1次万能救援+2次感染治疗，可自救，不赋予抗体。转职后原查验永久失效。

4.2 工程师（1人）

· 第1夜全能免疫（被动自动生效）。不受感染抑制影响。

· 维修数值见3.1节。追加维修（全局3次）须在基础后立即追加，每夜最多1次。【注释⑯】

· 每次维修后公告"工程师进行了维修"（不暴露编号）。

4.3 警察（1人）

· 初始2发子弹，每夜最多1枪，造成濒死，被抵挡即消耗。

· 巡逻（全局1次，仅第1/2/3夜可用）：与开枪互斥。指定1~3人获全能免疫。公告保护人数。

4.4 医生（生化专职医师×1、救援专职医师×1）

通用：每夜救援与感染治疗二选一；可主动向目标暴露身份；自身濒死时仍可使用自救。

职业 万能救援 感染治疗 特殊

生化专职医师 1次（仅自救），仅当自身濒死时可发动【注释㉑】 4次（初始1，第2/3/4夜各+1），含濒死【边界④】 清除1层+赋予抗体；自身免疫感染；治疗可对任意目标使用，但自身无效【注释⑲】

边界④："若该医生存活"含濒死状态。

4.5 神探（1人）

· 每夜查验1人（步骤2），结果仅本人可见：人类→具体职业；异形→"异形"；外星人→"外星人"。

· 被查者收到提示："你被查验了。"

4.6 保镖（1人）

· 每夜保护1名任意存活玩家（可自保，步骤3），使其当夜获得全能免疫。

· 目标受袭时，被保护者与保镖均可知晓伤害类型。

· 与警察巡逻、武装船员保护可叠加。

4.7 验票官（1人）

· 票型查看（被动）：白天投票阶段可查看每位存活玩家的投票目标（含弃权），仅本人可见。

· 紧急会议（全局1次，步骤10）：全场存活≥5且自身存活（未濒死）时可发动。【边界⑤】一经发动即消耗全局次数，无论投票结果如何。【注释㉓】公开身份，追加投票。规则完全复用1.5节（仅存活玩家参与、平票处理、身份公告、放逐立即生效）。【注释⑭】投票后立即结算胜利；若未触发胜利照常执行步骤11。【注释⑬】

边界⑤：验票官"自身存活"不含濒死（2.1总则：除医生自救外所有技能濒死失效）。

第五章：异形阵营

5.1 基础设定

· 异形共3名，开局互知身份，队内私聊仅夜间。

· 每夜每只异形从出刀/感染/破坏/结茧中选一项（互斥）。

· 濒死时所有技能失效。

· 选择破坏的，步骤4b执行破坏，步骤7不再行动。

5.2 觉醒系统（第3夜起可选，受额度限制）

· 全局额度：每个方向（破坏/感染/击杀）最多被2只异形选择。死亡不释放额度。

· 觉醒时机：第3夜起任意夜晚步骤0.6。可选，放弃不占额度，后续可重试。觉醒与转化不得同夜执行。【注释⑦】

· 觉醒方向：

· 破坏觉醒：破坏数值永久提升为 +3.0。

· 感染觉醒：感染目标数+1（1~2→2~3）。

· 击杀觉醒：偶数夜出刀+1。基准为游戏绝对夜数；选择后至少后天触发，若为奇数则顺延。【注释⑫】

· 第3夜前死亡/濒死则无法觉醒；脱离濒死后仍可觉醒。

· 觉醒公告："今晚有 X 只异形觉醒。"（不披露方向/编号）

· 失败处理：额度已满时失败，不消耗机会，可重试。

5.3 转化系统（额度限制 + 次数限制）——永久占位制

· 已觉醒异形可在任意夜晚步骤0.6选择转化，切换为另两种方向之一（不能与当前相同）。可选，放弃后可重试。觉醒后最早下一夜才能转化。【注释⑦】

双重限制：

1. 目标方向占位数必须 < 2。

2. 每只异形全局最多转化2次。

转化流程：

1. 检查目标方向占位数 < 2 → 否则失败，不消耗机会。

2. 检查已转化次数 < 2 → 否则失败。

3. 检查是否曾占用过目标方向：

· 已有标记 → 仅为切换方向，不增加占位数。

· 从未占用 → 占位数+1，获得标记。

4. 当前方向不减额（永久占位）。

5. 已转化次数+1。

6. 当前方向变更为目标方向（新能力次夜生效）。

转化作废条件：次夜步骤0.6前死亡/濒死 → 回滚（不公告、不计次数）。

转化公告：转化当夜不公告；次夜0.6结束时公告"有异形能力转化"（不披露编号/方向）；作废则不公告。

5.4 行动细则

· 出刀：每晚1次，命中非异形造成濒死；命中濒死目标时直接死亡。【注释⑪】击杀觉醒者在偶数夜额外出刀1次。

· 感染：可指定存活人类或外星人（不可选濒死/异形），上限1层。基础1~2名，觉醒后2~3名，由异形自主选择。【注释⑱】可被全能免疫抵挡，延迟死亡不可抵挡。同晚重复指定同一目标不叠加。

· 破坏：倒计时增加当前数值（未觉醒+1.5，觉醒+3.0）。累计破坏3次后下一白天公开编号+身份；若当夜后续死亡仍正常公告。【注释⑰】

· 结茧：仅对自身使用，跨夜护盾（上限1）。抵挡一次伤害后消失。结茧消耗当夜全部行动。已有护盾时再次结茧无效。

第六章：外星人阵营

6.1 基础规则

· 单兵作战，无队友。

· 不再免疫异形感染。作为补偿，拥有 2次 感染自我治疗。

· 每夜从三选一执行（互斥）：查验、击杀（含双刀）、破坏。若使用感染抑制则自动放弃三选一。

6.2 查验

· 每夜可查验1人，获知真实身份（编号+职业/阵营），无视隐藏。

· 被查验者收到提示："你被查验了。"

· 查验当夜不能击杀或破坏。

6.3 普通击杀

· 每晚击杀1人，造成外星人伤害濒死（若未使用查验或破坏）。

6.4 觉醒双刀（第7夜起可用）

· 触发夜：第7夜起可用。

· 公告"外星人要开始行动了"，不暴露身份。

· 每夜2次攻击。两刀可指向同一或不同目标。【注释⑩】

· 同目标：第一刀消耗抵挡/造成濒死；第二刀若目标已濒死则直接死亡。

· 不同目标：各自独立结算濒死。

· 沉默：每刀均附带沉默。被命中进入濒死的玩家（含被救活），下一夜开始沉默，持续整夜+次日白天。每名玩家全局仅触发1次。【注释⑩】

· 与查验、破坏互斥。

6.5 破坏船体

· 全局限1次。

· 倒计时增加 +3.0 昼夜。

· 附加效果：当夜步骤4a毛减量在步骤4b归零。

· 公告"外星人破坏船体×1"（不暴露编号）。

· 破坏当夜不能击杀或查验。

6.6 夜晚免疫（被动）

· 初始1次。

· 仅在非濒死状态下可触发【注释㉕】。受真实伤害时自动触发，当夜获得全能免疫，优先抵消该次伤害，不进入濒死。

· 被保护/护盾完全抵挡则不触发、不消耗次数。

· 触发后当夜剩余时间免疫所有伤害。

· 不受感染抑制影响。

注释㉕：夜晚免疫仅在非濒死状态下可触发（濒死者全部被动技能失效，2.1总则）。

第七章：跨阵营交互与通用规则

7.1 跨阵营交互允许表

· 医生救援：可救异形/外星人（救援专职医师可救任意；生化专职医师仅自救）。

· 警察巡逻：可指定异形/外星人。

· 查验技能：可查验异形/外星人（外星人无伪装能力）。

7.2 伤害与濒死

· 所有伤害（除注明"直接死亡"外）均造成濒死。

· 濒死者再次受击 → 直接死亡，不可救援。

7.3 子弹消耗

· 警察、武装船员的子弹，打出即消耗（无论是否被抵挡）。

7.4 沉默

· 沉默仅来自外星人觉醒双刀。

· 每名玩家全局仅触发1次，后续沉默源对其无效。

· 沉默不影响白天发言。

· 沉默与感染抑制叠加：见3.4节。
