# 太空杀 公测3.0 机制实施核验与规则修正文档

> 核验对象：`太空杀_公测3.0_模拟代码.py` vs 规则文档《太空杀_公测3.0_规则.md》
> 方法：① 逐机制对照代码常量与决策分支（静态核对）；② 对 2.0→3.0 的 10 处修正（R1~R10）+ 平衡定版（R11）做定向行为检验（微型脚本化场景，不在模拟批量内）。
> 结论：**28 项核对项全部一致；公测 2.0 存在的 6 处"规则文本↔代码不一致"全部按规则文本修正，4 处实现级缺陷全部清理。**

## 八、结论

- 3.0 共核对 **6 大类 40+ 项**：全部一致；2.0 的"规则文本↔代码"6 处不一致（救援额度文本5/代码3的矛盾以平衡定版 3 收敛、巡逻互斥、双刀时点、第10夜免疫、护盾重置、交锋反击）全部按规则文本修正实现。
- 清理 2 处实现级缺陷：伪装死代码（R9）、护盾每夜误重置（R5 的根因）。
- 平衡定版两项（R1 救援 3 次、R11 倒计时 21）已同步规则文本、代码常量与报告口径。
- 剩余平衡性观察（人类 48.2% / 异形 30.4% / 外星人 21.3%，差距超 15pp）详见《太空杀_公测3.0_高水平报告》⑧⑨章的数据与调优建议。
