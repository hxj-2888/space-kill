# 太空杀：三阵营对抗规则 公测3.0（正式发布版）

版本：公测3.0 ｜ 基于公测2.0 规则全量核对修正（R1~R10）+ 平衡定版与后续迭代（救援3次、倒计时24、感染体系v3、补刀第4夜/外星濒死第1夜）

> **公测3.0 文档定位**：本版是第一份"规则↔实现逐条核对"后的规则正文。2.0 及此前版本中，规则文本与模拟代码存在 10 处不一致（详见第八章变更表 R1~R10），本版以"规则文本为准"逐项修正了实现，并把此前口头约定、代码注释里才说得清的边界情形**全部写进正文**（标注【消歧】）。阅读本版规则不需要再翻代码。

## 第一章 基础配置与胜利条件

| 项目 | 数值 |
|------|------|
| 玩家总数 | 15 人 |
| 人类 | 11 人（普通船员×4、工程师、警察、生化医师、救援医师、神探、保镖、验票官） |
| 异形 | 3 只 |
| 外星人 | 1 只 |
| 初始倒计时 | 24 昼夜（公测3.1 平衡调整） |
| 停摆阈值 | 3.0 / 6.0 / 9.0（净破坏量） |
| 倒计时胜利 | 倒计时≤0 且未触发 9.0 永久失效 → 人类胜 |
| 清场胜利 | 异形+外星人全灭 → 人类胜；人类全灭且外星人灭 → 异形胜 |
| 外星人独存胜利 | 人类全灭且异形全灭、外星人存活 → 外星人胜 |
| 夜晚交锋 | 持续战斗至一方全灭存活方胜；单挑 1v1 三夜未分胜负→外星人胜；连续 5 夜无减员按人数判定；同归于尽→外星人胜 |

- **胜利条件优先级【消歧】**：每个结算节点（步骤9、白天驱逐、紧急会议、步骤11）结束时按上述顺序检查胜利，同一节点同时满足多条时按"人类清场 → 异形清场 → 外星人独存"的顺序判定先命中者。
- **夜数上限【消歧·R10】**：游戏不设夜数上限，持续进行直到一方胜利。模拟器内置 200 夜护栏（防极端死循环的技术兜底，不属于规则；护栏判平不计入任何阵营胜率口径）。
- **觉醒方向额度**采用【永久占位制】：不随死亡/转化释放，转化仅占用目标方向额度；一只异形可以同时在多个方向留下占位（历史占用集合不缩水）。

## 第二章 状态与流程

- 步骤顺序：**0 私聊 → 0.5 感染抑制 → 0.6 觉醒/转化/转职 → 1 外星人查验 → 2 查验/巡逻 → 3 保镖保护 → 4a 维修 → 4b 破坏 → 5 外星人击杀/双刀 → 6 警察/武装 → 7 异形行动 → 8 医生 → 9 死亡结算 → 10 验票官紧急会议 → 11 倒计时结算**。
- **步骤时点含义【消歧】**：序号在前的步骤先结算；同一步骤内多名玩家的行动按玩家编号顺序依次结算；前序步骤造成的"濒死/沉默/抑制"立即影响后续步骤的可用性。
- **夜晚交锋模式（人类全灭后）**：冻结步骤 0（私聊）、4a（维修）、4b（破坏）、步骤11（倒计时结算）与白天流程；仅保留 0.5/0.6/1/2/3/5/6/7/8/9 中仍可执行的行动与死亡公告，异形与外星人互相攻击直至一方全灭。
- **私聊**：每人每夜 1 次发起 + 1 次接受；配对需双向确认（发起方指定目标、被邀请方从邀请中选一人接受、且发起方当晚确实发起了对该目标的邀请，三方一致才成对）；**不可连续两晚向同一目标发起**（硬约束，对所有阵营生效）；异形队内私聊不受限且无公告。配对结果（仅"谁和谁聊了"）次日公开公告，**聊天内容不公开**。

## 第三章 核心数值机制

| 机制 | 数值/规则 |
|------|-----------|
| 工程师维修 | 第1/2夜 -0.5，第3夜起 -1.5 |
| 工程师追加维修 | -0.5，全局共 3 次，须在工程师本人完成基础维修的当夜立即追加，不可单独使用 |
| 普通船员协助维修 | -0.20 − 0.05×(X−1)，X=结算时存活普通船员数（含濒死，已转职者不计） |
| 加速工程师维修 | -0.75（转职获得，每夜可用） |
| 异形破坏 | 未觉醒 +1.5；破坏觉醒 +3.0 |
| 外星人破坏 | +3.0，全局 1 次；使用当夜不能击杀/查验；破坏后下一夜倒计时完全停转（自然流逝 0、维修无效） |
| 净破坏量 | 只累计破坏（异形+外星人），不受任何维修削减；停摆系统的唯一驱动量 |
| 维修者暴露 | 工程师/普通船员/加速工程师各自累计维修 3 次后，仅向所有异形与外星人公布其编号+当前职业 |
| 停摆奖励 | 3.0→倒计时 +1.5；6.0→倒计时 +3.0；9.0→人类倒计时胜利永久失效 |
| 感染 | 可感染人类与外星人；上限 1 层不叠加；感染后第 3 夜步骤 9 死亡（**感染觉醒异形施加的感染提前至第 2 夜**，公测3.1）；抑制延后 1 夜；生化医师治疗/救援清除感染并赋予抗体 |

- **倒计时记法【消歧】**：倒计时以"昼夜"为单位，每夜步骤11 自然 -1；维修为负向修正、破坏为正向修正、停摆奖励为正向追加，全部在同一数值轴上加减；倒计时可以高于初始值 24。
- **外星人停转夜【消歧】**：破坏发生当夜的步骤4b 记入破坏量；紧随其后的那一夜为"停转夜"——该夜步骤11 自然流逝为 0，且该夜步骤4a 的全部维修无效（维修量不结算；维修暴露计数照常累计）。
- **公测2.0 人类反破坏流（保留）**：净破坏量连续 2 夜每夜净增 ≥1.0 时，人类自动切换集中维修反制模式（普通船员维修倾向提升至 75%）。

## 第四章 人类阵营

| 职业 | 能力 |
|------|------|
| 普通船员 | 首次查验获"不是某职业"排除信息；同一目标累计查验 2 次锁定其真实阵营；每夜在"查验"与"协助维修"间二选一；转职（见下） |
| 工程师 | 第 1 夜被动全能免疫（当夜所有伤害免疫、不消耗）；每夜可维修 + 追加维修 |
| 警察 | 初始 2 发子弹，每夜最多开 1 枪；巡逻全局 1 次且仅限前 3 夜，指定 1~3 名玩家获得当夜保护；**巡逻与开枪同一夜二选一**（R2 消歧：只限制当夜，巡逻过的夜晚之后仍可正常开枪） |
| 生化医师 | 治疗额度 **4 次（初始 1 + 第2/3/4 夜各 +1）**；治疗/救援清除感染并赋予抗体；**自身不免疫感染（公测3.1 移除天生抗体）**；濒死时只能自救（消耗救援额度） |
| 救援医师 | **救援额度全局 3 次（初始 1 + 第2/4 夜各 +1）**（公测3.0 平衡定版；2.0 规则文本误写 5 次）；可救援任意濒死角色；治疗额度 1 次 |
| 神探 | 每夜查验 1 人真实身份（无视隐藏），查验结果仅自己知晓 |
| 保镖 | 每夜保护 1 人（含自保），被保护者当夜免疫 1 次伤害 |
| 验票官 | 白天可查看投票目标；全场存活 ≥5 且自身未濒死时可发动紧急会议（公开自身身份、追加一次白天投票、当夜跳过步骤11）；全场唯一一次 |

- **普通船员转职**：存活 ≤5 时可提前转职，或第 6 夜保底获得转职资格；方向三选一：武装船员（获 1 发子弹）、加速工程师（每夜 -0.75 维修）、临时医生（救援 1 次 + 治疗 2 次）。转职一次性，转职当夜起按新职业行动。
- **普通船员首次查验排除信息【消歧·R8】**：首次查验目标时获得"该目标不是【某职业】"的一条排除信息；排除的职业从**全部人类职业中随机选取，且保证不等于目标真实职业**（目标为异形/外星人时，任意人类职业的排除均为真命题）；同一查验者对同一目标的排除信息不重复发放。
- **濒死与行动【消歧】**：濒死者当夜起失去全部行动能力（含投票——白天投票强制弃权、夜间技能全部不可用），但不死亡、不解除阵营、医生救援后恢复；濒死状态下除医生自救外所有主动技能与被动技能（含全能免疫、护盾、夜晚免疫）全部失效，因此**濒死者再次受击直接死亡，不检查任何减免层**。

## 第五章 异形阵营

| 机制 | 规则 |
|------|------|
| 觉醒 | 第 3 夜起可觉醒（不强制）；方向 破坏/感染/击杀 三选一；每方向全局最多 2 只同时占用；公告"今晚有 1 只异形觉醒"（不公布方向） |
| 破坏觉醒 | 破坏量 +3.0/夜，推停摆阈值 |
| 感染觉醒 | 每夜可感染 2~3 名（未觉醒者 1~2 名）；目标存活人类或外星人、不可选濒死与异形；**其施加的感染提前至第 2 夜死亡（公测3.1）** |
| 击杀觉醒 | 偶数夜出刀 +1（该夜必须是偶数夜且晚于觉醒夜；觉醒当夜不触发） |
| 转化 | 永久占位制：已占用方向不释放；目标方向占用数须 <2；每只全局最多 2 次；转化当夜步骤7 无行动 |
| 出刀 | 每夜 1 刀，命中非异形（**含外星人**）造成濒死；被护盾/保护抵挡则无效果 |
| 感染 | 同上表；异形不感染异形 |
| 结茧 | 获得 1 层护盾，**护盾跨夜持续直到被打破**（R5 消歧：不再每夜清空）；已有护盾时再结茧无效；结茧消耗当夜全部行动；护盾只抵挡"伤害"（濒死类攻击与枪击），**不抵挡感染** |

- **异形行动菜单【消歧】**：每夜从 出刀/感染/破坏/结茧 中选择一项执行（觉醒方向只影响强化与倾向，不锁死行动）；选择破坏则在步骤4b 结算，当晚不再参与步骤7；被沉默或感染抑制的异形当晚无法执行任何行动。**异形队内协调**：同夜多只异形不重复指定同一健康目标（各自选择不同对象分摊打击面）。**补刀**（对已濒死目标再次出刀，直接致死——濒死再受击直接死亡的常规规则）按时点与来源受限：**异形出刀**造成的濒死，第 **4** 夜起方可补刀；**外星人攻击**造成的人类濒死，异形**第 1 夜起**即可补刀。限期内未补刀的濒死目标由医生救援竞争决定生死。
- **异形队内信息**：异形互相知晓队友身份；队内私聊无限制、无公告；破坏暴露信息对异形阵营公开。
- **异形静态风格基线（保留）**：标准策略为"感染开局→击杀收割"，动态破坏触发经 2.0 A/B 实测为净负面，默认关闭，仅保留策略矩阵的 sabotage/mix/stealth 模式钩子供平衡测试。

## 第六章 外星人阵营

| 机制 | 规则 |
|------|------|
| 查验 | 每夜可查验 1 人真实身份（无视隐藏），结果仅自己知晓；使用查验的当夜不能击杀/破坏 |
| 双刀 | **第 6 夜起**可选觉醒（可不觉醒，觉醒全局不可逆）；觉醒后永久获得双刀能力，每夜自主选择 双刀/单刀/单刀+查验（非强制每夜双刀）；**双刀命中并使目标进入濒死时附带沉默，同一玩家全局仅沉默 1 次** |
| 破坏 | +3.0，全局 1 次；使用当夜不能击杀/查验；破坏后下一夜倒计时停转 |
| 夜晚免疫 | 初始 1 次 + **第 10 夜额外 1 次**（R4，条件见下）；被保护/护盾完全抵挡时不触发不消耗；触发后当夜免疫后续所有伤害；免疫为自动触发，不需要玩家操作 |
| 感染自我治疗 | 2 次；每夜最多 1 次；仅未濒死时可用（濒死时所有被动技能失效） |
| 感染免疫 | **第 4 晚起免疫异形感染**（公测3.1 削弱；此前已感染的按原死亡夜结算） |
| 击杀 | 每夜 1 刀；人类全灭后的夜晚交锋中**可击杀异形**（R6 消歧） |

- **第 10 夜夜晚免疫【消歧·R4】**：当第 10 夜到来（或第 10 夜之后的任意夜）且首次出现"全局存活恰好 2 人、其中一人为外星人"的局面时，外星人额外获得 1 次夜晚免疫；该加强全局仅发放 1 次；若发放后未被消耗，**可带入夜晚交锋模式继续使用**。
- **双刀觉醒时点【消歧·R3】**：第 6 夜起（2.0 实现误为第 7 夜，以规则为准）。觉醒当夜即可使用双刀。
- **外星人查验目标【消歧】**：查验无视隐藏获得真实阵营与职业；查验不产生任何公告。

## 第七章 跨阵营交互与通用规则

| 规则 | 内容 |
|------|------|
| 伤害与濒死 | 所有伤害（出刀/枪击）造成濒死；濒死者再次受击直接死亡；濒死不解除感染，感染死亡照常结算 |
| 护盾与保护 | 护盾（结茧）与保护（巡逻/保镖/武装船员护卫）均抵挡 1 次伤害；完全抵挡时不触发目标的夜晚免疫、不消耗免疫次数；护盾不抵挡感染 |
| 子弹 | 打出即消耗（无论是否被抵挡）；警察巡逻夜不可开枪（同夜互斥） |
| 沉默 | 仅来自外星人双刀命中濒死；同一玩家全局仅 1 次；**不影响白天发言讨论，但次夜无法执行夜间技能、次日白天投票强制弃权**（即沉默覆盖 1 个完整昼夜循环） |
| 驱逐揭示 | 白天驱逐后公告："X号 是 阵营（职业：Y）"，含人类职业与异形/外星人身份，全体可见 |
| 紧急会议公告 | 发动时公告验票官编号与身份（R7 消歧："公开身份"为规则要求） |
| 夜晚交锋冻结 | 交锋期间倒计时/维修/破坏/停摆全部冻结；私聊暂停 |
| 公告清单【消歧】 | 每夜公开：私聊配对、觉醒次数（无方向）、查验/巡逻统计、维修总量、破坏次数与增量、倒计时值、死亡名单（编号+阵营+死因）、驱逐结果（编号+阵营+职业）、紧急会议、停摆触发。不公开：各玩家行动选择、查验结果、感染对象、保护目标、沉默对象、觉醒方向、额度余量 |

## 第九章 消歧汇总（2.0 时期未成文、本版明确）

1. **胜利检查优先级**：人类清场 → 异形清场 → 外星人独存，节点末尾统一判定。
2. **濒死者**：失去全部行动（含投票），可被救援恢复；再次受击直接死亡且不检查任何减免。
3. **护盾**：跨夜持续、上限 1 层、只挡伤害不挡感染；完全抵挡不触发夜晚免疫。
4. **沉默覆盖期**：命中夜次夜起算 1 个昼夜循环（1 夜技能封锁 + 1 次白天弃票）。
5. **巡逻互斥**：仅限巡逻当夜，不影响之后开枪。
6. **追加维修**：仅当夜紧随本人基础维修，全局 3 次，沉默/抑制当夜不可用。
7. **外星人停转夜**：仅影响次夜自然流逝与次夜维修结算，不叠加。
8. **感染与伤害独立**：濒死不阻断感染死亡计时；治疗清除感染不恢复濒死（救援才恢复）。
9. **同一步骤多人行动**：按玩家编号升序结算；保护类行动在对应伤害步骤之前生效。
10. **公告最小信息原则**：见第七章公告清单；任何"仅自己知晓"的信息不得进入公告与公开推理素材。
11. **异形转化公告**：转化当夜无行动；转化本身不公告（额度信息只有异形阵营可见）。
12. **模拟护栏**：200 夜判平仅是模拟器保险丝，正式规则不存在平局——对局必须进行到一方胜利。
13. **医生出手互斥【消歧】**：每名医生每晚仅一记出手——救援（濒死）与治疗（感染）互斥；有濒死者时医生优先尝试救援，出手后当晚不再治疗。
14. **感染觉醒死亡提前**：感染觉醒异形施加的感染，死亡夜为感染当夜的**次夜**（第 2 夜）；感染抑制仍可延后 1 夜。外星人自第 4 晚起对后续感染免疫，但先前感染照常结算。
15. **补刀（集中打击）时点**：异形同夜不重复指定同一健康目标；补刀按濒死来源分时点——**异形出刀**造成的濒死，**第 4 夜起**可补刀；**外星人攻击**造成的人类濒死，**第 1 夜起**即可补刀（外星人先手压制、异形收割的跨阵营协同）。濒死者是否被补刀或救援，构成每夜的击杀/救治博弈核心。

## 第十二章 典型对局结算示例（消歧用）

以下示例按规则步骤顺序逐步推演，用于裁定边界情形；与正文冲突时以正文为准，示例与正文同时冲突时以第八章变更表为准。

### 示例一：双刀沉默的完整时序

第 6 夜，外星人已觉醒双刀。步骤1 外星人未选查验；步骤5 外星人选择双刀，第一刀命中 7 号人类（无护盾、无保护），7 号进入濒死，由于是双刀命中且 7 号此前从未被沉默，7 号获得沉默（标记全局唯一）。第二刀命中 12 号人类，12 号进入濒死；12 号此前已被沉默过一次，**不再叠加沉默**。第 7 夜：7 号、12 号仍为濒死（未被救援），两者夜间技能全部不可用、感染抑制不可用；第 7 天白天：7 号、12 号投票强制弃权（可发言）。第 8 夜起沉默结束（濒死状态本身继续封锁行动，直至被救援或死亡）。

### 示例二：护盾与夜晚免疫的触发顺序

第 9 夜，异形出刀命中外星人（外星人此前已结茧，携带 1 层护盾，且夜晚免疫剩余 1 次）。按结算顺序：先查濒死（否）→ 工程师第1夜免疫（否）→ 全能免疫层数（0）→ **护盾**：护盾被打破，本次伤害被完全抵挡；因完全抵挡，夜晚免疫**不触发、不消耗**。若同夜第二刀（偶数夜击杀觉醒者）再次命中外星人：护盾已无，触发**夜晚免疫**（剩余 1→0），当夜后续所有伤害免疫。

### 示例三：感染与救援的竞争

第 3 夜，异形感染觉醒者感染 5 号人类（5 号感染死亡夜=第 5 夜）。第 4 夜，异形出刀使 5 号濒死。第 4 夜步骤8：救援医师使用救援（额度 3→2），5 号濒死解除；5 号的感染**仍在**（救援医师救援不清除感染——只有生化医师的治疗/救援清除感染并赋予抗体）。第 5 夜步骤9：5 号感染死亡照常结算。若第 4 夜救 5 号的是生化医师：5 号濒死解除、感染清除、获得抗体，第 5 夜不再死亡，且此后对感染永久免疫。

### 示例四：停转夜与停摆奖励的叠加

第 5 夜外星人使用破坏（+3.0，全局唯一），当夜净破坏量累计到 6.4 → 触发 6.0 阈值（倒计时 +3.0）。第 6 夜为停转夜：步骤4a 维修全部无效（工程师的维修量不结算但维修暴露计数照常累计），步骤11 自然流逝为 0。第 7 夜恢复正常：自然 -1，维修照常。

### 示例五：紧急会议与步骤11 的取舍

第 8 夜结束后，验票官发动紧急会议（存活 6 人 ≥5，自身未濒死）：公告验票官身份 → 追加一次白天讨论+投票 → 本夜跳过步骤11（倒计时本夜不减、停摆不结算）。紧急会议投票驱逐 1 名异形并触发人类清场 → 人类立即获胜，不再进入下一夜。若会议后无人被驱逐且未满足胜利条件，游戏进入第 9 夜（被跳过的步骤11 不补结算）。

### 示例六：1v1 铺路与单挑例外

第 15 夜人类仅剩 2 人，异形 2 只、外星人 1 只。外星人（已觉醒双刀）连续两夜各刀 1 只异形 → 第 17 夜起场上仅剩 1 异形 + 2 人类 + 1 外星人。第 18 夜异形刀、外星人刀人类，人类全灭 → 夜晚交锋：1 异形 vs 1 外星人。若连续三夜互不能造成减员（保护/护盾/免疫互相抵消）→ 第 21 夜判定**外星人胜**（单挑例外）。若交锋中某夜同归于尽 → 外星人胜。若交锋连续 5 夜无任何减员 → 按存活人数判定（1v1 时人数相等，判外星人胜）。

### 示例七：追责机制与驱逐公告的信息流

第 4 天白天，异形借白天发言指控 3 号人类并投出 3 号；驱逐公告揭示"3号 是 人类（职业：警察）"。追责机制：所有投票给 3 号的玩家被全体标记（怀疑度 +0.15），其中异形借此消耗人类的投票信誉；同时警察已死亡的公告意味着人类失去唯一的枪械威慑，人类的保护策略（保镖/巡逻目标）随之中转移向公开跳身份的神探。示例说明：驱逐公告的信息价值是双向的——人类获得阵营情报的同时，异形获得人类关键职业的死亡情报。

## 第十三章 常见问答与边界裁定（FAQ）

**Q1：濒死的玩家白天能发言吗？能被私聊邀请吗？**
能发言（发言不是"行动"），但投票强制弃权；私聊发起与接受属于行动能力，濒死者不可发起、不可接受，已完成的配对不受影响。濒死者也不可成为感染目标、不可被转职、不可被觉醒目标选中（各能力自带"不可选濒死"限制）。

**Q2：同一夜多名人类同时濒死，救援医师只有 1 次救援，怎么结算？**
救援医师按自己的偏好选择其中 1 名救援（消耗 1 次额度），其余濒死者维持濒死进入下一夜。生化医师濒死时只能自救且不救援他人；两名医生同时在场时各自独立决策，救援额度互不共享。

**Q3：警察被巡逻保护后同夜开枪，保护会转移吗？**
不会。巡逻的保护是施加在"被指定的 1~3 名玩家"身上的当夜免疫层，与警察本人当晚是否开枪无关；互斥只约束警察自己的两个技能不能同夜都用。

**Q4：外星人的破坏停转夜如果叠加停摆奖励会怎样？**
停摆奖励在破坏当夜的步骤4b 结算时立即加进倒计时；停转夜只冻结"下一夜的自然流逝与维修"。两者作用于不同夜晚，可以叠加。若停转夜恰好是游戏最后一夜（本应归零），倒计时维持不变，游戏继续。

**Q5：异形转化后，原方向的强化立即消失吗？**
是。转化在步骤0.6 结算，转化完成后异形按新方向获得强化、失去原方向强化；转化当夜步骤7 无任何行动。转化不公告，其他玩家（包括外星人）不知晓，只有异形阵营知道队内额度与方向。

**Q6：外星人查验得知的信息能公开说吗？**
外星人的查验结果仅自己知晓（规则未赋予任何公开身份的渠道）。外星人可以在白天"声称"任何内容（包括谎报查验结果制造迷雾），但没有驱逐揭示、紧急会议公告之外的官方渠道为其背书；其指控在信息密度统计中一律记为虚假指控。

**Q7：感染死亡与被刀同夜叠加怎么结算？**
步骤9 中感染延迟死亡与白天/夜间伤害死亡的结算互不干涉：感染死亡按 infection_death_night 触发，死亡公告合并公示。若感染者在达到死亡夜前被生化医师治疗，感染死亡取消；若在死亡夜当晚被救援（濒死状态不影响感染死亡），感染死亡仍触发。

**Q8：验票官紧急会议追加的投票可以再次驱逐上一轮的目标吗？**
可以，两次投票独立结算。紧急会议投票同样公示驱逐结果（阵营+职业）。若紧急会议驱逐导致清场胜利，游戏立即结束；否则当夜跳过步骤11，下一夜从步骤0 重新开始。

**Q9：200 夜护栏判平算谁的胜率？**
不属于任何阵营。正式对局不存在平局；模拟统计中平局单列一行（护栏判平），不计入三阵营胜率分母的比较结论。实测触发率接近 0%。

**Q10：异形"出刀含外星人"与"感染可选外星人"组合，异形能主动识别外星人吗？**
不能。异形不知道谁是外星人（外星人是独立阵营，隐藏身份）；出刀/感染的目标选择范围是"全部非异形存活玩家"，异形在选中后结算时才按规则对外星人生效。规则允许异形误伤外星人——这是三阵营博弈的结构性摩擦。

**Q11：普通船员转职后，原查验进度和排除信息还在吗？**
排除信息与已完成查验的结论（含锁定）保留——它们是"已获得的情报"，不因转职消失；但转职后不再拥有普通船员的查验行动权（转职职业按新职业行动）。

**Q12：夜晚交锋中人类的保护/维修技能还有意义吗？**
人类全灭后进入交锋，保镖/医生等人类技能随人类死亡自然退场；交锋中仅异形与外星人的夜间行动互殴，维修/破坏/倒计时全部冻结。若交锋前存在未结算的感染，感染死亡照常在交锋期间触发（感染无阵营）。

## 第十四章 平衡定版说明（救援医师与倒计时）

公测3.0 发布前的最后一批平衡调整基于 2.0 基线的高水平模拟观察：AI 3.0 升级后人类胜率显著上行（确定性击杀与证据分级采信使人类误驱率大幅下降），三阵营出现"人类过强、异形承压、外星人垫底"的格局。经评估采取两项定版调整：

1. **救援医师削弱（R1 定版）**：救援额度全局 5 次 → **3 次**（初始 1 + 第2/4 夜各 +1）。救援医师是人类濒死挽回的核心资源，削弱后异形击杀的"濒死→死亡"转化率回升，异形击杀流价值提高。
2. **倒计时延长（R11）**：初始倒计时 20 → **21 昼夜**。给人类多 1 夜缓冲以对冲救援削弱带来的中后期减员压力，同时微调停摆系统的节奏（3.0/6.0 阈值相对价值略降，9.0 的永久失效更具威慑）。

两项调整与 AI 3.0 的综合效果见《太空杀_公测3.0_高水平报告》的总体结果与平衡性章节；报告同时给出后续数值调优建议（如异形觉醒时机、外星人免疫额度）的数据依据。
