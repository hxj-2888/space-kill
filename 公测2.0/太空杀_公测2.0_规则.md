# 太空杀：三阵营对抗规则 公测1.2.1（正式发布版）

版本：公测1.2.1 ｜ 基于内测2.0规则数值 + 公测1.2.1策略层优化

## 第一章 基础配置与胜利条件

| 项目 | 数值 |
|------|------|
| 玩家总数 | 15 人 |
| 人类 | 11 人（普通船员×4、工程师、警察、生化医师、救援医师、神探、保镖、验票官） |
| 异形 | 3 只 |
| 外星人 | 1 只 |
| 初始倒计时 | 20 昼夜 |
| 停摆阈值 | 3.0 / 6.0 / 9.0（净破坏量） |
| 倒计时胜利 | 倒计时≤0 且未触发9.0永久失效 → 人类胜 |
| 清场胜利 | 异形+外星人全灭 → 人类胜；人类全灭且外星人灭 → 异形胜 |
| 夜晚交锋 | 持续战斗至一方全灭存活方胜；单挑1v1三夜未分胜负→外星人胜；连续5夜无减员按人数判定；同归于尽→外星人胜 |

- 觉醒方向额度采用【永久占位制】：不随死亡/转化释放，转化仅占用目标方向额度。

## 第二章 状态与流程

- 步骤顺序：0私聊 → 0.5感染抑制 → 0.6觉醒/转化/转职 → 1外星人查验 → 2查验/巡逻 → 3保镖保护 → 4a维修 → 4b破坏 → 5外星人击杀/双刀 → 6警察/武装 → 7异形行动 → 8医生 → 9死亡结算 → 10验票官紧急会议 → 11倒计时结算。
- 私聊：每人1次发起+1次接受；配对需双向确认；不可连续两晚向同一目标发起（规则硬约束，所有策略生效）；异形队内不受限无公告。

## 第三章 核心数值机制

| 机制 | 数值/规则 |
|------|-----------|
| 工程师维修 | 第1/2夜 -0.5，第3夜起 -1.5 |
| 工程师追加维修 | -0.5 全局共3次，须在基础维修后立即追加 |
| 普通船员协助维修 | -0.20 - 0.05×(X-1)，X=存活普通船员数 |
| 加速工程师维修 | -0.75 |
| 异形破坏 | 未觉醒 +1.5；破坏觉醒 +3.0 |
| 外星人破坏 | +3.0 全局1次，破坏后下一夜倒计时完全停转（自然流逝0、维修无效） |
| 净破坏量 | 只累计破坏，不受维修削减 |
| 维修者暴露 | 工程师/普通船员/加速工程师各累计3次后，仅向所有异形/外星人公布编号+职业 |
| 停摆奖励 | 3.0→+1.5倒计时；6.0→+3.0倒计时；9.0→倒计时胜利永久失效 |
| 感染 | 可感染人类与外星人；上限1层；感染后第3夜步骤9死亡；抑制延后1夜；生化医师治疗赋予抗体 |

- **公测1.2.1 人类反破坏流**：净破坏量连续2夜净增≥1.0时，人类自动切换集中维修反制模式（普通船员维修率提升至75%）。

## 第四章 人类阵营

| 职业 | 能力 |
|------|------|
| 普通船员 | 首次查验获"不是某职业"排除信息，累计2次锁定阵营；转职（存活≤5提前或第6夜保底）→武装船员/加速工程师/临时医生（转职后 救援1次+治疗2次） |
| 工程师 | 第1夜被动全能免疫；维修+追加维修 |
| 警察 | 初始2发子弹每夜最多1枪；巡逻全局1次仅前3夜指定1~3人，与开枪互斥 |
| 生化医师 | 治疗额度4次（初始1+第2/3/4夜各+1）；治疗/救援清除感染并赋予抗体；自身免疫异形感染 |
| 救援医师 | 救援额度全局5次（初始3+第2/4夜各+1，以代码 L278/L457 实测为准）；可救援任意角色 |
| 神探 | 每夜查验1人真实身份（无视隐藏） |
| 保镖 | 每夜保护1人，可自保 |
| 验票官 | 白天可看投票目标；全场存活≥5且自身**未濒死**可发动紧急会议（公开身份、追加投票、跳过步骤11）——濒死时技能失效（2.1总则） |

## 第五章 异形阵营

| 机制 | 规则 |
|------|------|
| 觉醒 | 第3夜起；每方向全局最多2只；额度不随死亡释放 |
| 破坏觉醒 | +3.0，推停摆阈值 |
| 感染觉醒 | 感染目标2~3名（基础1~2名） |
| 击杀觉醒 | 偶数夜+1刀 |
| 转化 | 永久占位制（不释放旧方向）；目标方向占位<2；每只最多2次；转化当夜无行动 |
| 出刀 | 命中非异形（含外星人）造成濒死 |
| 感染 | 指定存活人类或外星人（不可选濒死/异形）；上限1层 |
| 结茧 | 护盾上限1，已有护盾再结茧无效；结茧消耗当夜全部行动 |

- **公测1.2.1 异形动态破坏触发**：异形劣势局面（存活≤2 / 已有异形公开暴露 / 人类信息网成型）时，觉醒与行动自动转向破坏优先——用破坏推停摆锁死人类倒计时，把游戏拖入对自己更有利的残局。

## 第六章 外星人阵营

| 机制 | 规则 |
|------|------|
| 查验 | 每夜可查验1人真实身份（无视隐藏）；与击杀/破坏互斥 |
| 双刀 | 第6夜起可选觉醒（可不觉醒）；觉醒后永久获得双刀能力，**每夜可自主选择双刀 / 单刀+查验**（以代码实测为准，非强制每夜双刀）；命中濒死者附带沉默（同一玩家全局仅1次） |
| 破坏 | +3.0 全局1次，使用当夜不能击杀/查验；破坏后下一夜倒计时停转 |
| 夜晚免疫 | 初始1次 + 第10夜额外1次（仅 1v1：全局存活恰好2人【外星人对单对手】时触发，全局限1次；若第10夜该次未被消耗，可带过进入夜晚交锋模式继续使用；公测1.2.1加强）；被保护/护盾完全抵挡不触发不消耗；**触发后当夜免疫所有伤害** |
| 感染 | 不再免疫异形感染；拥有2次感染自我治疗（每夜最多1次；仅未濒死且未被直接死亡时触发，濒死时失效——2.1总则：除医生自救外所有被动技能失效） |

## 第八章 名词解释

| 术语 | 解释 |
|------|------|
| **三阵营** | 人类（11人，目标：撑到倒计时归零或清场异形+外星人）、异形（3只，目标：人类全灭且外星人已灭）、外星人（1只，目标：残局独存或夜晚交锋胜）。 |
| **昼夜 / 倒计时** | 初始倒计时 20 昼夜（玩家配置表）。每夜结算后倒计时 -1；倒计时≤0 且未触发 9.0 永久失效 → 人类胜利。**已解除夜数上限**：游戏持续进行直到一方胜利（倒计时归零/清场/夜晚交锋判定），不再受"最多20昼夜"限制。 |
| **停摆阈值 3.0 / 6.0 / 9.0** | 由"净破坏量"累计触发的奖励节点：3.0→+1.5 倒计时；6.0→+3.0 倒计时；9.0→倒计时胜利永久失效（人类再也无法靠倒计时取胜）。 |
| **净破坏量** | 只累计所有破坏（+1.5/+3.0），**不受任何维修削减**。是停摆系统的唯一驱动量。 |
| **维修** | 工程师/普通船员/加速工程师降低倒计时下降速度（第1/2夜 -0.5，第3夜起 -1.5 等），但**不影响已累计的净破坏量**。 |
| **永久占位制** | 觉醒方向额度（每方向全局最多2只）一旦被某异形占用，不随该异形死亡或转化而释放；转化仅占用"目标方向"的新额度，旧方向仍占位。 |
| **觉醒** | 异形第3夜起可在 破坏/感染/击杀 三个方向之一觉醒，获得对应强化；每方向全局最多2只同时觉醒。 |
| **转化** | 异形改变自身觉醒方向（永久占位制），每只最多2次，目标方向占位<2，转化当夜无行动。 |
| **感染** | 异形指定存活人类/外星人施加上限1层感染；第3夜步骤9死亡（抑制延后1夜）；生化医师治疗可清除并赋予抗体。 |
| **出刀 / 濒死** | 异形出刀命中非异形造成"濒死"（失去行动、再次受击直接死亡）；护盾/保护可抵挡。 |
| **结茧** | 异形获得护盾（上限1，已有护盾再结茧无效），消耗当夜全部行动，用于蓄力或规避风险。 |
| **沉默** | 仅来自外星人双刀命中濒死者，"同一玩家全局仅1次"，不影响白天发言。 |
| **驱逐揭示（公开公告）** | 白天驱逐后公告"X号 是 阵营（职业：Y）"，含人类职业，对全体公开，用于驱动追责机制与后续信念更新。 |
| **私聊** | 每人每夜1次发起+1次接受，配对需双向确认，不可连续两晚向同一目标发起；异形队内私聊无公告。 |
| **验票官紧急会议** | 全场存活≥5 且验票官**未濒死**可发动，公开身份、追加投票、跳过当前夜步骤11（倒计时结算）；濒死时失效（2.1总则）。 |
| **夜晚交锋** | 异形/外星人/人类夜间残余兵力持续战斗至一方全灭；单挑1v1三夜未分胜负→外星人胜；连续5夜无减员按人数判定；同归于尽→外星人胜。交锋期间倒计时/维修/破坏/停摆全部冻结。 |
| **信息密度指数 IDI** | 本夜有效私聊数×1 + 公开指控总具体度×1 − 虚假指控数×1。用于量化每夜信息战活跃度。 |
| **有效私聊率** | 私聊总次数中，48h内对私聊对象产生行为变动的比例（本模型 50.6%）。 |
| **指控具体度（0~3级）** | 0级泛泛怀疑→3级确证信息；级别越高驱逐正确率越高（本模型 15.4%→95.5%）。 |

## 第十章 高水平模拟与策略矩阵核心结论摘要

> 本章合并两份交付报告（公测1.2.1 高水平报告、公测1.2.1 策略矩阵报告）的关键文本，确保单文档即可查阅全部结论。

### 10.1 高水平模拟（5000局）核心结论（公测1.2.1，含核心数值修正 + 第10夜免疫=1v1触发 + std默认）

> 本版含规则修正：夜晚交锋冻结维修/破坏、警察巡逻/开枪互斥、工程师第1夜全免疫、感染抑制延迟修正、解除夜数上限。以下数据为修正后 5000 局实测。

- **总体胜率**：人类 38.5% / 异形 32.2% / 外星人 29.4%；平均游戏 9.19 夜（最长25夜，因解除夜数上限，停摆9.0失效后靠清场拖长）。
- **胜利原因**：异形清场 32.1% > 外星人独存 21.4% > 人类清场 20.7% > 人类倒计时 17.8% > 夜晚交锋单挑平局 7.9%。
- **外星人（1v1触发版）**：第10夜免疫 1v1 触发后，外星人胜率 29.4%，显著高于 1.1 基线(24.2%)——双刀强制收割+夜晚交锋冻结维修使外星人残局获益。外星人仍为三阵营垫底，但差距收窄。
- **停摆系统**：3.0 触发率、6.0/9.0 触发率详见报告（已计入夜晚交锋冻结维修/破坏后的净破坏累积变化）。
- **信息密度量化**：有效私聊率 50.6%；指控具体度 0→3 级驱逐正确率逐级提升（3级达95%）；IDI 前中期高、后期随存活减少回落。
- **平衡性提示**：随机基线人类胜率反高于高水平，说明异形/外星人从"策略化"获益仍大于人类——人类处于结构性信息劣势。

### 10.2 策略矩阵（24组合 × 2000局）核心结论（公测1.2.1）

| 关键观察 | 结论 |
|----------|------|
| 人类主动广播是铁律 | passive(神探不跳)使人类暴跌至 33.0%、异形飙至 49.0%+；std/aggro 维持 40~42% |
