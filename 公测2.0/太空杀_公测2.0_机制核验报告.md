## 八、需修正的规则表述

### ⚠️ 修正1：救援医师救援额度（规则表述与代码不符）

- **规则现写**：`救援额度3次（初始1+第2/4夜各+1）`
- **代码实际**（L278）：`救援医师初始化 doctor_rescue = 3`，且 L457-459 第2/4夜再各 +1
- **实际总额度**：**5 次**（初始3 + 第2夜+1 + 第4夜+1），而非规则声称的 3 次
- **修正建议**（二选一）：
  1. **改规则**（以代码为准）：`救援医师救援额度：初始3次 + 第2/4夜各+1 = 全局5次`
  2. **改代码**（以规则为准）：L278 改为 `doctor_rescue = 1`，与 L451 注释"初始1"一致
- **影响评估**：救援医师多 2 次救援会显著提升人类中后期对濒死的救治能力，属**有利于人类的加强**；若设计意图是"初始1"，建议修代码；若意图是"初始3"，修规则。

### ⚠️ 修正2：遗漏临时医生（转职）额度

- **规则未提及**：普通船员转职"临时医生"的能力额度
- **代码实际**（L635-637）：转职为临时医生后 `doctor_rescue = 1, doctor_treat = 2`
- **修正建议**：在第四章人类职业表补充：`临时医生（转职）：救援1次 + 治疗2次`

### ⚠️ 修正3：外星人夜晚免疫触发细节可补充

- **规则现写**：`被保护/护盾完全抵挡不触发不消耗`
- **代码实际**（L337-340）：触发后 `t.immune = 999`，**当夜剩余时间免疫所有伤害**；护盾检查在前，护盾抵挡不消耗免疫 ✓
- **修正建议**：补充一句：`触发后当夜免疫所有伤害`（强化表述精确性）

### ⚠️ 修正4：高水平报告摘要数据过期

- **规则第十章 10.1**：仍写 1000 局数据（人类42.7/异形33.3/外星人24.0）
- **最新 5000 局**：人类41.5/异形33.5/外星人25.0（report_high_5000_ob121.md）
- **修正建议**：10.1 标题与数据更新为 5000 局版本

- 26 项机制中，**22 项完全一致**，**1 项不符（救援医师额度）**，**1 项遗漏（临时医生额度）**，2 项建议补充精确性/数据。
