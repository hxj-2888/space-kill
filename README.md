# 太空杀：三阵营对抗 · 公测3.0

15 人三阵营（人类 11 / 异形 3 / 外星人 1）身份博弈桌游的**规则设计 + 自动化平衡性模拟**项目。

- **裁判逻辑 100% 确定性**，严格按照各版本规则步骤顺序结算。
- **玩家 AI 带策略与信息博弈**：私聊三层信息交换、白天讨论节奏、投票追责、信息迷雾；严格禁止「上帝视角」——只能使用自己已知信息 + 公开公告。
- 通过**大规模自动化对局**输出阵营胜率、职业强度与平衡性报告，用数据驱动规则迭代（公测 1.0 → 2.0 → 3.0）。

## 公测3.0 核心变化

**规则↔实现逐条核对（以规则文本为准）**：修正 2.0 的 6 处文本/代码不一致——救援医师额度定版 3 次、巡逻与开枪改为同夜互斥、双刀觉醒回归第 6 夜、恢复外星人第 10 夜夜晚免疫（1v1 触发）、结茧护盾跨夜持续、夜晚交锋外星人可击杀异形；另完成紧急会议公开身份、排除信息池修正、伪装死代码清理、解除夜数上限（200 夜仅为模拟护栏）、初始倒计时 20→21 平衡定版。完整清单见《公测3.0_规则.md》第八章变更表 R1~R11 与《机制核验报告》（18/18 行为检验通过）。

**AI 3.0 升级（A1~A7）**：警察/武装船员确定性击杀（查验确证必开枪）、异形白天协同 scapegoat 投票、人类证据分级采信（低证据弃权降误驱）、外星人"建图→双刀收割→1v1 铺路"时序、追加维修与转职的资源经济、信息枢纽打击。

**5000 局高水平模拟结果**（规则 3.0 + AI 3.0）：人类 48.2% / 异形 30.4% / 外星人 21.3%，平均 9.40 夜；随机基线对照与平衡性分析见高水平报告。

> ⚠️ **当前状态**：模拟代码有待完善，自由决策未完全实现（部分场景依赖预设策略分支），模拟结论供参考，不等同于真人玩家的完整决策空间。
