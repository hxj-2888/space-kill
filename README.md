# 太空杀：三阵营对抗 · 公测1.0

15 人三阵营（人类 11 / 异形 3 / 外星人 1）身份博弈桌游的**规则设计 + 自动化平衡性模拟**项目（公测1.0）。

- **裁判逻辑 100% 确定性**，严格按照公测1.0 规则的步骤顺序结算。
- **玩家 AI 带策略与信息博弈**：私聊三层信息交换、白天讨论节奏、投票追责、信息迷雾；严格禁止「上帝视角」——只能使用自己已知信息 + 公开公告。
- 通过**大规模自动化对局**输出阵营胜率、职业强度、策略矩阵与平衡性报告，用数据驱动规则调优。

## 文件

| 文件 | 内容 |
