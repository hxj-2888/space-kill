# 太空杀：三阵营对抗 · 公测1.2

15 人三阵营（人类 11 / 异形 3 / 外星人 1）身份博弈桌游的**规则设计 + 自动化平衡性模拟**项目。

- **裁判逻辑 100% 确定性**，严格按照各版本规则步骤顺序结算。
- **玩家 AI 带策略与信息博弈**：私聊三层信息交换、白天讨论节奏、投票追责、信息迷雾；严格禁止「上帝视角」——只能使用自己已知信息 + 公开公告。
- 通过**大规模自动化对局**输出阵营胜率、职业强度、策略矩阵与平衡性报告，用数据驱动规则迭代（公测 1.0 → 1.1 → 1.2）。

## 公测1.2 关键变化

- 异形动态破坏触发（A/B 实测为净负面，默认关闭，切回静态感染→击杀流）
- 人类反破坏流（净破坏加速检测 → 集中维修）；统计口径修复（end_reason 带阵营前缀）
- 工程师第 1 夜被动全能免疫 / 外星人夜晚免疫 / 普通船员首次查验获得排除信息
- 策略矩阵模式层：`human_mode`（std/passive/aggro）、`alien_mode`（std/**mix**/sabotage/stealth）、`foreigner_mode`（std/hunter）
  - **公测1.2 默认 `alien_mode='mix'`**：矩阵实测 mix(38.4%) > std(37.3%)，"1 破坏 + 2 感染击杀"的少数派破坏战术更优
- 外星人第 10 夜额外 +1 夜晚免疫（终局保命牌：全局存活 ≤3 时触发，全局仅 1 次）
- 信息密度量化：指控具体度分级(0-3)、有效私聊率、IDI 逐夜指数（纯打标统计，不改博弈逻辑）
